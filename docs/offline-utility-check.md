# Manual check: department Offline Utility (testing layer 3)

Not automatable - the Common Offline Utility is a desktop app. Run this
**before every release that touches `service/json_builder/` and before the CA
review**. Record each run in the table at the bottom.

## Procedure (per golden case, at least 01, 02, 03, 04, 06)

1. Download the current ITR-1 Offline Utility for AY 2026-27 from
   https://www.incometax.gov.in/iec/foportal/downloads and note its version.
2. Take `itr_json` from the case's `.expected.json` and save it alone as
   `case_NN.json`. Replace the fictional PAN with a test PAN you control if the
   utility checks PAN format/checksum online.
3. In the utility: open the JSON as a return to resume/edit (do NOT use
   "prefill" - that path pulls from the portal and overwrites figures).
4. Expect a clean import: no schema/parse error dialog.
5. Walk every tab and compare against `summary` and the hand working in
   `docs/golden-review.md`:
   - Gross total income, Chapter VI-A total, total income
   - Tax, 87A rebate, cess, net liability (note rounding - see ROUNDING_288B)
   - 234A / 234B / 234C / 234F
   - Taxes paid, balance payable / refund
6. Click "Calculate tax" / validate. Record every error or warning the utility
   raises verbatim.
7. "Generate JSON" from the utility and diff it against ours
   (`python -m json.tool` both, then `diff`). Expected differences:
   CreationInfo (SW ID, digest, dates). Anything else is a builder bug or an
   open question below.
